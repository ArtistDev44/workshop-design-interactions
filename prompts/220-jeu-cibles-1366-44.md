# Prompt 220 — Jeu : cibles à 44 px CSS sur les petits écrans d'ordinateur (1366 × 768)

Origine : prompt 218 (§ Vérifié) et demande du 15/11/2026 (« passe aussi les cibles à 44 px en 1366 »).
Statut : **exécuté le 15/11/2026**.

## Constat

Sur ordinateur, l'image du jeu (1920 × 1080) est réduite à la taille de la fenêtre : ×0,71 en 1366 × 768. Une cible
de 44 px de l'image y fait 31 px CSS. Mesuré (prompt 218) : 303 cibles entre 31 et 44 px CSS, médiane 32.

## Principe

La taille qui compte (WCAG 2.5.5 / 2.5.8) est celle de la **zone qui reçoit le clic**, pas du dessin. À chaque image,
quand l'image est réduite (échelle < 1), chaque cible de moins de 44 px CSS voit sa zone de clic agrandie autour
d'elle jusqu'à 44 px CSS, **sans jamais empiéter sur une cible voisine** (au plus jusqu'à mi-chemin). Le dessin ne change
pas ; le curseur « main » suit la zone agrandie. Là où les cibles sont trop serrées pour cela, agrandir le dessin.

## Vérification

`npm run build`, `npm test` ; mesure des cibles en px CSS (prompt 214) : **0 cible sous 44 px CSS en 1366 × 768**,
1920 × 1080 et mobile inchangés (0) ; 0 défaut de texte ; un clic au bord d'une zone agrandie déclenche la bonne
cible (Chromium).

## Fait

- `elargirCibles()` (`sketch.js`, en fin d'image) : sur ordinateur, quand l'image est réduite, chaque cible de moins de
  45 px CSS (1 px de marge sur l'arrondi) est agrandie côté par côté jusqu'au bord de l'image ou à mi-chemin de la
  voisine en face ; ce qu'un côté ne peut pas prendre passe au côté opposé.
- Cibles trop serrées pour cela : `hSerre(h, s)` (`ds.js`) agrandit le dessin, seulement quand l'image est réduite —
  jetons des équipes, boutons de la bulle du guide, « +3 autres » / « Tout effacer » du téléphone, dossiers de Mails,
  − / + des curseurs, pas des pastilles de couleur (`pasCouleurs`).

## Vérifié

- `npm run build`, `npm test` (+5 contrôles, dont une simulation de deux voisines).
- **1366 × 768 : 0 cible sous 44 px CSS** (303 avant), 0 défaut de texte ; 1920 × 1080, 412 × 915 et 915 × 412 : 0 et 0.
- Chromium 1366 × 768 : un clic sous « Quitter le PC », dans la zone agrandie mais hors du dessin, quitte bien le PC.
- 1280 × 720 (hors objectif) : 25 cibles entre 40,8 et 44 px CSS.
