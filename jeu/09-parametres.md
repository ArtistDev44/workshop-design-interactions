# 09 — Paramètres

## Paramètres réglables (écran d'accueil ou pause)
- [ ] **Semaine à rejouer** : sélection dans les limites de l'API (ou semaine de
  référence du fallback).
- [ ] **Mode en ligne / hors ligne** : forcer le fallback local.
- [ ] **Durée du compteur** par décision (difficulté : facile / normal / difficile).
- [ ] **Son** : activé / coupé.
- [ ] **Accessibilité** : réduction des animations (`prefers-reduced-motion`),
  contraste renforcé, taille du texte.
- [ ] **Reset** : touche `R` pour recommencer la semaine.

## Persistance
- Les réglages peuvent être conservés en `localStorage` (jamais de secret).
