# Instructions personnelles — Design interaction / PATRIMOINE.EXE NTE001

Règles de travail personnelles pour ce dépôt. Toute personne ou assistant IA qui intervient sur le projet les lit avant de modifier quoi que ce soit. Ce fichier est la référence des règles actives ; le livret et le framework dans contexte/ restent la référence des attentes pédagogiques.

## Règles actives

- Langue de travail : français.
- Chaîne à tenir : source → grammaire → système → œuvre. Aucun ajout technique sans justification dans cette chaîne.
- todo.md est la référence unique des tâches : cocher les cases au fur et à mesure ; la vue d'ensemble 3 jours en tête du fichier sert de suivi rapide du protocole.
- contexte/ contient les références du projet : livret étudiant, framework, et le présent fichier. Elles font foi ; ne pas les modifier sans raison.
- prompts/ contient les prompts numérotés qui créent le site Astro.js de l'édition. Les mettre à jour dès que le contexte, le todo ou la structure du projet changent.
- À chaque push sur un dépôt du projet (atelier ou site), mettre à jour journal.md à la racine : une ligne par push, la plus récente en tête, avec date, commit, fichiers touchés et résumé.
- Un QR code pointant vers le site web en ligne de l'œuvre doit figurer sur le cartel : généré, intégré, et scanné en conditions réelles avant l'exposition.
- Respecter le standard du framework : 7 invariants, checklist de robustesse, accessibilité.
- Déclarer tout usage d'IA dans le README (note AI usage de 3 à 5 lignes).
